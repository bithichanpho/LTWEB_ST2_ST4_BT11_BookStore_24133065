## Admin – Quản lý đơn hàng

Đăng nhập bằng `admin@store.com` / `admin` rồi vào menu **Quản lý đơn hàng**

- **Danh sách đơn:** thống kê nhanh (tất cả / mới / đang xử lý / đã giao), lọc theo trạng thái, ô tìm nhanh theo mã đơn, tên khách, SĐT, phân trang 10 đơn/trang.
- **Chi tiết đơn:** sản phẩm, tổng tiền, thông tin người nhận, thanh tiến trình và nút xử lý.
- **Quy trình trạng thái**:

```
Đơn mới → Đã xác nhận → Chuẩn bị hàng → Vận chuyển → Giao hàng → Đã giao

```
